# My Pocket Phone

아이폰 iOS 디자인을 기반으로 한 인터랙티브 가상 스마트폰 웹사이트를 만들어 줘. 잠금화면부터 시작하고, 비밀번호를 눌러 잠금해제할 수 있는 화면으로 만들어줘. 홈 화면에는 메시지, 사진, 메모, 음악, b.stage, 카메라, 카카오톡, 전화 앱을 배치해 줘. 각 아이콘을 누르면 실제 앱처럼 해당 화면이 열리게 해 줘. 메시지 작성, 메모 편집, 사진첩 보기, 음악 재생 UI, 전화 다이얼 패드 등 각 기능도 구현해 줘. 홈 버튼과 뒤로 가기, 상태 표시줄을 포함하고 모바일과 PC에서 모두 작동하게 해 줘. 캐릭터의 프로필, 대화, 사진을 나중에 쉽게 수정할 수 있도록 만들어 줘. 완성 후 링크로 공유할 수 있게 배포해 줘.
